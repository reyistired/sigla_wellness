# Contributing to Sigla Wellness

Thank you for your interest in contributing!

## Getting Started

1. Fork the repository
2. Clone your fork
3. Create a new branch: `git checkout -b feature/your-feature`
4. Install dependencies: `npm install`
5. Start the dev server: `npm run dev`

## Development Guidelines

- Follow the existing code style and conventions
- Keep components small and focused
- Test your changes across different screen sizes
- Update documentation if needed

## Submitting Changes

1. Commit your changes with a clear message
2. Push to your fork
3. Open a Pull Request with a description of what you changed and why

## Reporting Issues

- Use the GitHub issue tracker
- Include steps to reproduce the issue
- Include your browser and OS information

## Code Style

- Use functional components with hooks
- Follow the existing CSS variable naming conventions
- Keep component files in the `src/components/` directory
- Keep data/content in the `src/data/` directory
